# Anexo G — Consentimiento informado y protocolo de usabilidad (SUS)

**Estado: no se realizaron evaluaciones con participantes humanos** en la versión evaluada (ver §6.3 del
TDDR). Este anexo deja preparados el protocolo y el formulario para la evaluación de usabilidad prevista
como trabajo futuro; no contiene datos de participantes.

## G.1 Protocolo propuesto

- **Objetivo**: medir la usabilidad percibida con la escala SUS [4] y la tasa de éxito en tareas.
- **Participantes**: N ≥ 12 personas que analizan datos en su trabajo o estudio sin ser analistas de
  datos (administrativos, docentes, estudiantes de últimos ciclos). Criterios de inclusión: mayores de
  18 años, uso habitual de hojas de cálculo, sin experiencia programando análisis. Exclusión: haber
  participado en el desarrollo.
- **Tareas** (con `examples/relacionadas/`):
  1. Crear un proyecto y subir los cinco archivos relacionados.
  2. Indicar, a partir de la foto del esquema, qué tabla se abre primero y por qué.
  3. Encontrar en la pestaña Dataset cuántos valores vacíos tiene una columna.
  4. Encontrar en Investigación un factor relacionado con la nota y si es significativo.
  5. Filtrar el dashboard por una carrera y descargar el informe PDF.
- **Medidas**: éxito por tarea (sí/no), tiempo por tarea, errores, SUS al final, comentarios abiertos.
- **Análisis**: SUS de 0 a 100 (impares: respuesta − 1; pares: 5 − respuesta; suma × 2,5); media,
  desviación e IC 95 %; comparación con el umbral de referencia 68.

## G.2 Cuestionario SUS (escala 1 = totalmente en desacuerdo … 5 = totalmente de acuerdo)

1. Creo que me gustaría usar este sistema con frecuencia.
2. Encontré el sistema innecesariamente complejo.
3. Pensé que el sistema era fácil de usar.
4. Creo que necesitaría el apoyo de una persona técnica para poder usar este sistema.
5. Encontré que las distintas funciones del sistema estaban bien integradas.
6. Pensé que había demasiada inconsistencia en el sistema.
7. Imagino que la mayoría de las personas aprendería a usar este sistema muy rápidamente.
8. Encontré el sistema muy engorroso de usar.
9. Me sentí muy seguro/a usando el sistema.
10. Necesité aprender muchas cosas antes de poder empezar a usar este sistema.
